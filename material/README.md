# Material de centrales térmicas — Geotermia

Fuentes de consulta para el desarrollo de los trabajos del curso **Centrales
Termoeléctricas**. Los seis documentos son tesis y trabajos académicos sobre
energía y centrales geotérmicas.

> **Aviso de derechos de autor.** Los PDF pertenecen a sus autores y
> universidades. Se incluyen únicamente como material de estudio académico; no se
> redistribuyen con fines comerciales. Para citarlos, usar los datos
> bibliográficos de la tabla.
