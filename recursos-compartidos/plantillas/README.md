# Plantillas

Plantillas propias del proyecto, de uso obligatorio para mantener estructura
uniforme y permitir verificaciones automáticas.

| Plantilla | Uso |
|---|---|
| `PLANTILLA_FICHA_EQUIPO.md` | Fichas de equipos en `03_equipos/` |
| `PLANTILLA_MEMORIA_CALCULO.md` | Memorias de cálculo en `05_calculos/` |
| `PLANTILLA_SEGUIMIENTO_CAPITULOS.md` | Control de estados en `00_gestion/` |
| `PLANTILLA_FUENTE.md` | Registro bibliográfico `SRC-NNN` |
| `PLANTILLA_PRESENTACION.md` | Presentaciones ENT-01 a ENT-03 |

## Reglas

1. Copiar la plantilla al destino; no editar la plantilla original para un caso
   particular.
2. No eliminar campos: si no aplica, escribir «No aplica» y justificar.
3. Si una plantilla debe cambiar, se modifica aquí y se registra en
   `CHANGELOG.md` con el impacto en los documentos ya creados.
