# Recursos compartidos

Material de apoyo común a los cinco trabajos. Nada de lo aquí contenido sustituye
al registro bibliográfico: toda fuente usada debe quedar registrada en
`BIBLIOGRAFIA_GENERAL.md`.

| Carpeta | Contenido permitido | Contenido prohibido |
|---|---|---|
| `normas/` | Fichas de normas, extractos de libre distribución, enlaces oficiales | PDFs completos de normas con derechos de autor |
| `libros/` | Fichas bibliográficas, notas propias de lectura | Copias de libros protegidos |
| `tablas-termodinamicas/` | Tablas propias, datos de fuentes abiertas citadas | Escaneos de tablas de libros |
| `plantillas/` | Plantillas Markdown y LaTeX propias | Plantillas de terceros sin licencia compatible |
| `referencias/` | Informes públicos (DOE, EPA, IEA, IRENA), artículos de acceso abierto | Artículos de pago |

## Reglas

1. Cada archivo incorporado debe indicar origen, licencia y fecha de consulta en
   el `README.md` de su carpeta o en el registro de fuentes.
2. Los datos numéricos (poder calorífico, propiedades, curvas) siempre se citan;
   nunca se presentan como propios.
3. Si un documento no puede redistribuirse, se guarda solo su ficha y el enlace.
4. Las tablas y plantillas propias se versionan; los archivos grandes se evitan.
