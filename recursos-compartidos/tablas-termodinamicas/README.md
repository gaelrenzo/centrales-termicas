# Tablas termodinámicas

Propiedades del agua y del vapor necesarias para los cálculos del ciclo Rankine.

## Política

- Solo se incorporan tablas propias, tablas de fuentes abiertas o datos
  transcritos con cita exacta (tabla, página, edición).
- Prohibido escanear o copiar tablas de libros protegidos.
- Cada tabla declara: sustancia, sistema de unidades, fuente (`SRC-NNN`) y fecha.
- Los valores usados en cálculos se referencian a la tabla y a la fila/interpolación.
