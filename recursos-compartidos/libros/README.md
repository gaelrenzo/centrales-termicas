# Libros

Referencias bibliográficas de libros universitarios especializados.

## Política

- Solo se guardan fichas bibliográficas y notas propias de lectura; nunca copias
  de libros protegidos.
- Los datos (título, edición, año, editorial, ISBN) se transcriben del ejemplar
  consultado.
- Las notas de lectura indican capítulo y página para poder verificar el dato.
