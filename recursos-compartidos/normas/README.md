# Normas

Fichas y extractos de normas aplicables a centrales térmicas.

## Política

- No se almacenan PDFs completos de normas con derechos de autor (ASME, IEC, API,
  NFPA, ASHRAE). Solo fichas, datos bibliográficos y enlaces oficiales.
- Cada norma se registra con su ficha `SRC-NNN` y estado `VERIFICADA` antes de
  citarse.
- Se indica la edición o revisión vigente y la fecha de consulta; las normas se
  actualizan, y una edición obsoleta debe declararse como tal.

## Ficha mínima por norma

```
Organismo · Código · Título · Edición/Año · Alcance aplicado · SRC-NNN · Estado
```
