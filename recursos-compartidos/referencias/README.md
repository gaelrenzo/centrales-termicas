# Referencias

Documentos públicos de libre acceso: informes del DOE, EPA, IEA e IRENA,
artículos de acceso abierto, guías técnicas y manuales de fabricante de
distribución libre.

## Política

- Verificar la licencia antes de incorporar un archivo.
- Cada documento lleva su ficha `SRC-NNN` con URL oficial y fecha de consulta.
- Se conserva la versión descargada solo si la licencia lo permite; en caso
  contrario se guarda el enlace.
- Indicar siempre la fecha de publicación del informe, porque los datos
  energéticos se actualizan periódicamente.
