
## 3. Reglas

1. Una norma pasa a `VERIFICADA` solo con la edición a la vista.
2. Se indica la sección concreta aplicada, no la norma completa.
3. Si la edición disponible está derogada, se declara y se busca la vigente.
4. Las exigencias normativas se describen; no se reproduce su texto extenso.
5. Cuando una norma no esté accesible, se registra como `PENDIENTE` y no se
   cita como requisito cumplido.
