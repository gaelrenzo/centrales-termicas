## 3. Reglas

1. Cada anexo se numera y se cita desde el cuerpo del informe.
2. Un anexo amplía evidencia; no introduce conclusiones nuevas.
3. Los datos de fabricante indican modelo, documento y fecha de consulta.
4. No se anexan documentos con derechos de autor.
5. La nomenclatura del anexo A es la referencia para todos los capítulos.

## 4. Qué no va aquí

- Capítulos del informe (van en `../capitulos/`).
- Archivos PDF de normas o libros.
- Figuras sueltas (van en `../figuras/` o en `../../../06_diagramas/`).
